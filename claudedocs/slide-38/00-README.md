## 🎯 功能概述

为 Ghost 添加书签功能,允许已登录会员保存文章以便稍后阅读。

### 核心特性
- ✅ **添加/移除书签**: 在文章页面一键保存或取消保存
- ✅ **查看书签列表**: 在 Portal 会员区查看所有已保存文章
- ✅ **自动主题集成**: 通过 `{{ghost_head}}` 自动注入,无需主题修改
- ✅ **会员专属**: 仅已登录会员可用,所有会员等级均可访问

### MVP 范围
**包含**:
- 基础的保存/取消保存功能
- 简单的书签列表查看
- 按保存时间排序
- 分页加载

**不包含** (未来迭代):
- 书签分类/标签
- 阅读进度追踪
- 书签笔记
- 书签搜索/过滤

## 🏗️ 技术架构

### 后端
- **数据库**: 新建 `members_bookmarks` 表
- **API**: Members API 新增 4 个端点
- **权限**: 基于会员会话的访问控制

### 前端
- **Bookmarks UI**: 新建 React 应用 (`apps/bookmarks-ui`)
- **Portal 集成**: 新增书签列表页面
- **主题集成**: 自动注入 JavaScript 和 CSS

### 关键技术选择
| 组件 | 技术 | 理由 |
|------|------|------|
| 数据存储 | 独立表 | 可扩展性、查询性能 |
| 主题集成 | 自动注入 | 零配置、即插即用 |
| 状态管理 | React Query | 专注服务端状态、内置缓存 |
| 模块格式 | UMD | 浏览器兼容性 |
| API 位置 | Members API | 会员功能、权限模型 |
