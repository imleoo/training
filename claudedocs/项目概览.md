# 📊 Ghost 项目概览

## 项目简介
**Ghost** 是一个开源的专业发布平台（Professional Publishing Platform），采用 Headless CMS 架构，基于 Node.js 构建。

- **仓库**: https://github.com/TryGhost/Ghost
- **许可证**: MIT
- **组织**: Ghost Foundation
- **下载量**: 100M+

---

## 🏗️ 项目架构

### Monorepo 结构
使用 **Yarn v1 Workspaces + Nx** 管理的 monorepo，包含 3 个主要工作区：

```
training/
├── ghost/*          # 核心 Ghost 包
├── apps/*           # React UI 应用
└── e2e/             # E2E 测试
```

---

## 📁 核心目录结构

### 1️⃣ **ghost/** - 核心包组
```
ghost/
├── core/       # 主应用 (Node.js/Express 后端)
├── admin/      # Ember.js 管理后台 (正在迁移到 React)
└── i18n/       # 国际化中心化管理 (60+ 语言)
```

**ghost/core** 关键目录：
- `core/server/` - 核心服务器逻辑
- `core/frontend/` - 前端渲染
- `core/server/api/` - API 路由
- `core/server/data/schema/` - 数据库架构
- `core/server/services/` - 业务服务
- `core/server/models/` - 数据模型

### 2️⃣ **apps/** - React 应用组
分为两类应用：

**管理应用** (嵌入 Ghost Admin):
- `admin-x-settings` - 设置界面
- `admin-x-activitypub` - ActivityPub 集成
- `posts` - 文章分析
- `stats` - 站点统计
- `admin` - Ember.js 管理后台 (legacy)

**公共应用** (面向访客):
- `portal` - 会员门户
- `comments-ui` - 评论系统
- `signup-form` - 注册表单
- `sodo-search` - 搜索功能
- `announcement-bar` - 公告栏

**基础库**:
- `admin-x-framework` - 共享 API hooks、路由、工具
- `admin-x-design-system` - 旧设计系统 (正在淘汰)
- `shade` - 新设计系统 (shadcn/ui + Radix UI + react-hook-form + zod)

### 3️⃣ **e2e/** - E2E 测试
- 基于 Playwright 的端到端测试
- Docker 容器隔离

## 🛠️ 技术栈

### 后端技术
- **运行时**: Node.js
- **框架**: Express.js
- **数据库**: MySQL
- **缓存**: Redis
- **包管理**: Yarn v1
- **构建工具**: Nx

### 前端技术
- **现代应用**: React + Vite + TanStack Query
- **管理后台**: Ember.js (逐步迁移到 React)
- **设计系统**: shadcn/ui + Radix UI
- **表单验证**: react-hook-form + zod
- **状态管理**: @tanstack/react-query
- **构建**: Vite (React apps), UMD bundles (公共应用)

### 基础设施
- **容器化**: Docker + Docker Compose
- **反向代理**: Caddy
- **邮件测试**: Mailpit
- **对象存储**: MinIO (可选)
- **分析**: Tinybird (可选)

## 🔄 构建依赖顺序

Nx 自动处理以下构建顺序：

```
1. shade + admin-x-design-system
   ↓
2. admin-x-framework
   ↓
3. Admin React apps (admin-x-settings, posts, stats, etc.)
   ↓
4. ghost/admin (Ember, 通过 asset-delivery 复制)
   ↓
5. ghost/core (服务构建的 admin)
```

## 🎯 开发工作流

### 后端开发
1. 核心逻辑 → `ghost/core/core/server/`
2. API 路由 → `ghost/core/core/server/api/`
3. 数据模型 → `ghost/core/core/server/models/`
4. 主题渲染 → `ghost/core/core/frontend/`

### 前端开发
1. **新功能** → 使用 React (`apps/admin-x-*` 或 `apps/posts`)
2. **设计系统** → 使用 `shade`（不要用 admin-x-design-system）
3. **API 集成** → 使用 `admin-x-framework` 的 hooks
4. **翻译** → 添加到 `ghost/i18n/locales/en/ghost.json`

---

## 📌 注意事项

1. **包管理器**: 始终使用 `yarn`，不要用 `npm`
2. **设计系统**: 新组件使用 `shade`，避免 `admin-x-design-system`
3. **构建顺序**: Nx 自动处理，无需手动管理
4. **开发模式**: `yarn dev` 是推荐的开发方式（Docker + 主机混合）
5. **提交信息**: 遵循项目规范（emoji + 过去式 + issue 引用）

## 🔍 微前端架构详解

### Admin Apps 集成机制

**构建流程**:
1. Admin-x React 应用使用 Vite 构建到 `apps/*/dist`
2. `ghost/admin/lib/asset-delivery` 将构建产物复制到 `ghost/core/core/built/admin/assets/*`
3. Ghost admin 从 `/ghost/assets/{app-name}/{app-name}.js` 提供服务

**运行时加载**:
- Ember admin 使用 `AdminXComponent` 动态导入 React 应用
- React 组件包裹在 Suspense 和 error boundaries 中
- 通过 `additionalProps()` 方法接收配置

### Public Apps 集成

- 构建为 UMD bundles → `apps/*/umd/*.min.js`
- 通过主题模板中的 `<script>` 标签加载（由 `{{ghost_head}}` 注入）
- 通过 data 属性传递配置

### i18n 架构

**集中化翻译**:
- 单一来源: `ghost/i18n/locales/{locale}/{namespace}.json`
- 命名空间: `ghost`, `portal`, `signup-form`, `comments`, `search`
- 支持 60+ 语言环境

## 🧪 测试架构

### 测试类型
```
ghost/core/test/
├── unit/              # 单元测试
├── integration/       # 集成测试
├── e2e/               # API E2E 测试
└── browser/           # Playwright 浏览器测试

e2e/                   # 项目级别 E2E 测试
└── tests/             # Playwright 测试套件
```

### 运行测试
```bash
# Ghost Core 测试
cd ghost/core
yarn test:unit         # 仅单元测试
yarn test:integration  # 集成测试
yarn test:e2e          # E2E API 测试
yarn test:browser      # Playwright 浏览器测试
yarn test:all          # 所有测试类型

# 单个测试
yarn test:single test/unit/path/to/test.test.js

# 项目级别 E2E
yarn test:e2e          # 从根目录运行
```

## 🎨 提交规范


- ✨ 新功能

- 🌐 国际化/翻译

```
fixes https://github.com/TryGhost/Ghost/issues/12345
```
