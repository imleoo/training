## 💡 使用建议

### 初次阅读
1. **不要跳过"项目概览"**：这是建立全局认知的基础
2. **结合图表阅读**：可视化图表能帮助快速理解复杂关系
3. **动手验证**：边读边在代码中验证文档所述内容
4. **做笔记**：记录自己的理解和疑问

### 深入学习
1. **跟踪实际流程**：使用调试器跟踪"文章创建流程"
2. **对比代码**：将文档中的代码片段与实际代码对比
3. **扩展阅读**：查阅文档中提到的官方文档和源码注释

### 问题解决
1. **善用搜索**：在 VS Code 中全局搜索关键词
2. **查看调用链**：使用 IDE 的"查找引用"功能
3. **参考测试**：`ghost/core/test/` 目录下的测试是最好的示例

## ❓ 常见问题

**Q: 文档太长，如何快速上手？**
A: 先读"项目概览"和"架构文档"的前两章，然后直接看"文章创建流程追踪"来理解实际业务流程。

**Q: 文档和代码不一致怎么办？**
A: 以代码为准，并提交 Issue 或 PR 更新文档。代码是唯一的事实来源。

**Q: 如何验证文档中的代码路径？**
A: 使用 `ls` 命令或 IDE 的文件导航功能检查路径是否存在。

**Q: 图表看不清楚？**
A: SVG 文件可以在浏览器中打开并无限放大，或使用支持 SVG 的编辑器查看。
